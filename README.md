# Notch Control

Pannello per il notch del MacBook: musica con barrette a ritmo, prossimo evento, batterie dei dispositivi e un Cassetto per i file.

**Scarica:** [NotchControl-1.1.zip](NotchControl-1.1.zip)

Serve un MacBook con il notch e macOS 14.2 o successivo. Le istruzioni sono nel file Leggimi dentro lo zip. Gli aggiornamenti arrivano da soli.
